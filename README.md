## 📌 Course Overview & Syllabus

This course introduces theoretical foundations and computational techniques for designing intelligent agents capable of optimal or near-optimal decision-making across complex environments. Topics span problem-solving via state-space search, constraint satisfaction, game theory, logic-based reasoning, probabilistic inference under uncertainty, reinforcement learning, and modern application domains.

### 🔹 Classical, Informed & Local Search Strategies
* **Uninformed & Informed Search:** BFS, DFS, Iterative Deepening, Uniform Cost Search (UCS), Greedy Best-First Search, A* Search, and admissibility/consistency proofs for heuristic functions.
* **Local Optimization & Continuous Search:** Hill-climbing, Simulated Annealing, Local Beam Search, Genetic Algorithms, and continuous space optimization via Gradient Descent.
* **Constraint Satisfaction Problems (CSPs):** Backtracking search, constraint propagation heuristics (MRV, LCV, Forward Checking, MAC, AC-3), and local search formulations for CSPs.

### 🔹 Adversarial Games, MDPs & Reinforcement Learning
* **Adversarial Search & Games:** Minimax evaluation, Alpha-Beta pruning strategies, and stochastic games via Expectiminimax.
* **Markov Decision Processes (MDPs):** Dynamic programming frameworks, Bellman equations, Policy Evaluation, Value Iteration, and Policy Iteration.
* **Reinforcement Learning (RL):** Model-based vs. model-free control, Temporal Difference (TD) learning, and model-free Q-Learning.

### 🔹 Knowledge Representation, Logic & Probabilistic Inference
* **Formal Logic & Inference:** Propositional logic, resolution inference rules, First-Order Logic (FOL), and knowledge-based agent representation.
* **Bayesian Networks:** Graph representation, conditional independence, exact inference, approximate inference via sampling techniques, and parameter estimation.
* **Probabilistic Sequential Models:** Markov Chains, Hidden Markov Models (HMMs), and Naïve Bayes classifiers.

### 🔹 Foundations of Machine Learning & Applied AI
* **Machine Learning Fundamentals:** Linear models, optimization strategies, and Multi-Layer Neural Networks.
* **Applied AI Domains:** Introduction to Natural Language Processing (NLP), Computer Vision (CV), and Autonomous Robotics.
